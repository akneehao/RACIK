Before you start a new build

Racik plans around what's already in Current Stock — leftovers it can use up instead of buying fresh. If stock hasn't been updated since the last delivery, the new build may assume less (or more) is on hand than actually is.

Methodology & limitations

The solver always returns a menu. When the budget can't meet every AKG floor, the shortfall is reported here rather than hidden — a bar shown in red is a floor that had to be relaxed, not an error.

Micronutrients (calcium, iron, zinc, vitamin A, vitamin C, sodium) are informational only — AKG 2019 values disagree across secondary sources and aren't enforced as constraints. They're not editable in Crafting's nutrition step either, only the five macros are.

Cost is calculated on gross purchased weight (BDD), not edible weight.
